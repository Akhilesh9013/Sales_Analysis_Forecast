# 📊 Sales Analysis & Forecasting Project

## 📌 Project Overview

This project focuses on analyzing retail sales data and building forecasting models to predict future weekly sales across different stores and departments. The analysis helps businesses understand sales trends, seasonal demand, holiday impacts, and store performance to support better inventory planning and business decisions.

The project includes:

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Sales Trend & Seasonal Analysis
* Holiday Impact Analysis
* Store & Department Performance Analysis
* Machine Learning Based Forecasting
* Business Insights & Recommendations

# 🔍 Key Analysis Performed

## ✅ Data Preprocessing

* Cleaned and formatted date columns
* Handled missing values and duplicates
* Created time-based features like Year, Month, and Week
* Prepared data for analysis and forecasting

## 📈 Exploratory Data Analysis (EDA)

* Analyzed sales distribution and outliers
* Compared store-wise and department-wise performance
* Studied seasonal sales patterns
* Evaluated holiday impact on weekly sales
* Identified high-performing and low-performing business areas

## 📊 Sales Insights

* Sales data is highly right-skewed with extreme holiday spikes
* November and December show strong seasonal growth
* Some stores and departments contribute significantly higher revenue
* Holiday weeks generate higher and more volatile sales
* Sales patterns vary across locations and departments
